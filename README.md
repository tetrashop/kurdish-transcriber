# رونویسی زنده کردی (Kurdish Live Transcriber)

## چکیده (Abstract)
این پروژه یک اپلیکیشن وب مبتنی بر معماری بدون سرور (Serverless) است که با استفاده از Next.js توسعه یافته و قادر است سیگنال‌های صوتی زبان کردی (سورانی) را به صورت بلادرنگ (Real-time) دریافت، پردازش و به متن تبدیل کند. فرآیند پردازش صدا به دلیل محدودیت‌های پهنای باند و تأخیر (Latency) در سمت کلاینت (مرورگر) تکه‌تکه (Chunking) شده و از طریق یک API واسط در Vercel به سرویس‌های تشخیص گفتار (STT) ارسال می‌شود.

## معماری سیستم (System Architecture)
پروژه از یک معماری سه‌لایه بهره می‌برد:
1. **لایه کلاینت (Client-side):** ضبط صدا با استفاده از Web Audio API، اعمال الگوریتم تشخیص فعالیت صوتی (VAD) بر اساس آستانه انرژی (RMS)، نرمال‌سازی نرخ نمونه‌برداری (Resampling به 16kHz) و کدگذاری به فرمت WAV (PCM 16-bit).
2. **لایه میانی (API Route):** یک تابع Serverless در Vercel که نقش پروکسی امن را ایفا می‌کند. این لایه از افشای کلیدهای API در سمت مرورگر جلوگیری کرده و فرمت درخواست (FormData) را برای سرویس‌دهنده نهایی بهینه‌سازی می‌کند.
3. **لایه سرویس‌دهنده (STT Provider):** ارسال داده‌های صوتی به مدل Whisper (Large-v3) جهت استخراج متن.

## تکنولوژی‌های استفاده شده
* **فریم‌ورک:** Next.js 14 (App Router)، React 18
* **زبان برنامه‌نویسی:** TypeScript
* **پردازش صدا:** Web Audio API (`AudioContext`, `ScriptProcessorNode`)
* **استقرار (Deployment):** Vercel

## چالش‌های فنی و راه‌حل‌ها (Technical Challenges)
1. **توهم‌زنی مدل (Model Hallucination):** ارسال قطعات صوتی کوتاه (کمتر از ۳ ثانیه) باعث تولید کلمات نامفهوم توسط Whisper می‌شد. با افزایش طول هر قطعه به ۸ ثانیه (`CHUNK_MS = 8000`)، دقت رونویسی به طور چشمگیری افزایش یافت.
2. **مدیریت صف درخواست‌ها (Queue Management):** برای جلوگیری از همپوشانی درخواست‌ها و خطاهای شبکه، یک صف مبتنی بر `Promise` در سمت کلاینت پیاده‌سازی شد تا هر قطعه تنها پس از دریافت پاسخ قطعه قبلی ارسال شود.
3. **محدودیت‌های سرویس‌دهنده‌ها:** 
   * سرویس‌های داخلی (مانند Hormouz) به دلیل محدودیت دسترسی از سرورهای خارج از ایران (Vercel) دچار خطای Timeout (502) می‌شدند.
   * سرویس Hugging Face با محدودیت اعتبار مواجه شد (402).
   * سرویس Groq از کد زبان کردی (`ku`) پشتیبانی نمی‌کند؛ راه‌حل استفاده از کد زبان فارسی (`fa`) یا انگلیسی جهت حفظ الفبای صحیح بود.
   * سرویس DeepInfra به دلیل نیاز به اعتبار مالی اولیه (402) مسدود شد.
4. **سازگاری با محیط توسعه (Termux/Android):** رفع خطاهای لینکر (Linker) در Node.js بر روی اندروید با به‌روزرسانی کتابخانه‌های `libc++` و `openssl`.

## متغیرهای محیطی (Environment Variables)
برای اجرای صحیح پروژه، باید یکی از کلیدهای زیر در تنظیمات Vercel (یا فایل `.env.local`) تعریف شود:
* `GROQ_API_KEY` (پیشنهادی - سریع‌ترین سرویس)
* `DEEPINFRA_API_KEY` 
* `HUGGINGFACE_API_KEY`
