# رونویسی زنده کردی (Kurdish Live Transcriber)

## چکیده (Abstract)
این پروژه یک سامانه پردازش زبان طبیعی (NLP) و رونویسی بلادرنگ (Real-time) است که با استفاده از معماری بدون سرور (Serverless) توسعه یافته است. این سامانه قادر است سیگنال‌های صوتی زبان کردی (سورانی) را دریافت، با استفاده از الگوریتم‌های پردازش سیگنال نویززدایی کرده و به متن تبدیل کند. خروجی نهایی علاوه بر متن رونویسی‌شده، شامل ترجمه روان به زبان فارسی است.

## معماری سیستم (System Architecture)
پروژه از یک معماری سه‌لایه بهره می‌برد:
1. **لایه کلاینت (Client-side):** ضبط صدا با استفاده از Web Audio API، اعمال الگوریتم تشخیص فعالیت صوتی (VAD) بر اساس آستانه انرژی (RMS)، نرمال‌سازی نرخ نمونه‌برداری (Resampling به 16kHz) و کدگذاری به فرمت WAV (PCM 16-bit).
2. **لایه میانی (API Route / Proxy):** یک تابع Serverless در Vercel که نقش واسط امن را ایفا می‌کند. این لایه با پیاده‌سازی مکانیزم Rate Limiting (محدودیت ۱۰ درخواست در دقیقه برای هر IP) از سوءاستفاده جلوگیری کرده و کلیدهای API را از دید کلاینت پنهان نگه می‌دارد.
3. **لایه سرویس‌دهنده (AI Providers):** استفاده از مدل `whisper-large-v3` برای تشخیص گفتار (STT) و مدل `llama-3.1-8b-instant` برای اصلاح متن و ترجمه (Translation) به صورت یکپارچه در سرویس Groq.

## چالش‌های فنی و راهکارهای علمی (Technical Challenges & Solutions)
1. **توهم‌زنی مدل (Hallucination):** مدل‌های STT در مواجهه با سکوت یا نویزهای طولانی، کلمات بی‌ربط تولید می‌کنند (مانند "موسیقی"). 
   * *راه‌حل:* پیاده‌سازی فیلتر VAD قوی در سمت کلاینت (عدم ارسال سکوت) و اضافه کردن فیلتر کلمات توهم‌زا در سمت سرور.
2. **محدودیت زبان کردی در Groq:** سرویس Groq کد زبان `ku` را پشتیبانی نمی‌کند.
   * *راه‌حل:* تنظیم زبان روی `fa` (فارسی) به دلیل اشتراک الفبا، و استفاده از پرامپت‌های مهندسی‌شده در مدل زبانی (LLM) برای تشخیص مفهوم کردی و ترجمه آن به فارسی روان.
3. **مدیریت همزمانی (Concurrency):** ارسال درخواست‌های همزمان باعث خطاهای شبکه و قفل شدن صف می‌شد.
   * *راه‌حل:* پیاده‌سازی صف مبتنی بر Promise در فرانت‌اند و استفاده از `AbortController` برای مدیریت تایم‌اوت‌ها (۲۰ ثانیه).

## متغیرهای محیطی (Environment Variables)
برای اجرای پروژه در محیط Production (Vercel)، متغیر زیر الزامی است:
* `GROQ_API_KEY`: کلید API سرویس Groq (با پیشوند `gsk_`).

## نصب و استقرار (Installation & Deployment)
\`\`\`bash
# نصب وابستگی‌ها
npm install

# اجرای محیط توسعه محلی
npm run dev
\`\`\`
برای استقرار، کافیست مخزن را به Vercel متصل کرده و متغیر محیطی `GROQ_API_KEY` را در تنظیمات آن تعریف کنید.
